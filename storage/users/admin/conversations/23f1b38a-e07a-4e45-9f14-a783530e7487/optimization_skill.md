Standard Operating Procedure: High-Speed Centrifugation
(Method A)
1.0 Purpose: Defines operating procedure for laboratory high-speed preparative centrifuge units.
2.0 Scope: Applies to all centrifugation runs in the active bio-pharmaceutical manufacturing facility.
3.0 Responsibilities: Operators must be certified. Supervisors must verify equipment calibration log.
4.0 Equipment & Materials: Model Beckman J2-21 Centrifuge, Fixed-angle JA-10 rotor, Balanced sample
bottles.
5.0 Pre-Operational Checks: Visually inspect rotor for cracks or corrosion. Verify rubber O-ring seal integrity.
6.0 Procedure:
6.1 Balance opposing centrifuge bottles with analytical precision within ± 0.05 grams.
6.2 Secure rotor onto drive spindle with locking knob. Ensure seated flush without wobble.
6.3 Set centrifugation speed to 4500 RPM. Set chamber cooling temperature to 4°C.
6.4 Set run duration to 25 minutes. Engage vacuum latch mechanism.
6.5 Press Start. Observe acceleration curve until target speed is achieved.
6.6 Upon cycle completion and deceleration to 0 RPM, vent vacuum chamber and carefully retrieve bottles.
7.0 Documentation: Record run date, speed (4500 RPM), operator initials, and lot ID in equipment log book.

Operating Guide: High-Speed Centrifugation Protocol
(Method B)
1.0 Purpose and Objective: Standard guidelines for executing high-speed centrifuge separation processes.
2.0 Scope: Applicable to all production and QC laboratory centrifuge equipment.
3.0 Operating Personnel: Only trained production associates may operate centrifuge machinery.
4.0 Apparatus: High-speed preparative centrifuge, JA-10 rotor assembly, balance scale.
5.0 Inspection Steps: Inspect the rotor well for debris. Inspect rotor O-ring and lubricate lightly if dry.
6.0 Operational Procedure:
6.1 Accurately balance sample containers against counterpart bottles on twin-pan balance (± 0.05 g).
6.2 Mount rotor onto drive hub and tighten retaining nut firmly clockwise.
6.3 Program rotational velocity to 5000 RPM. Set refrigeration system to 2°C.
6.4 Program timer for 30 minutes. Secure vacuum barrier door.
6.5 Initiate rotation. Monitor instrument sound and vibration levels during ramp-up.
6.6 Following complete deceleration, disengage safety lock and extract sample containers.
7.0 Batch Record Entry: Document operator signature, actual rotational speed (5000 RPM), and temperature
in batch log.

Standard Operating Procedure: Secondary Blister Packaging
& Cartoning
1.0 Purpose: Guidelines for packaging solid dose pharmaceutical tablets into PVC/PVDC foil blisters.
2.0 Scope: Packaging Line 4 primary and secondary packaging suites.
3.0 Responsibilities: Packaging operators and Quality Assurance batch reviewers.
4.0 Equipment: Uhlmann Blister Machine B1240, cartoner module, vision inspection system.
5.0 Setup: Load PVC forming web. Set forming station heater to 135°C. Load aluminum backing foil.
6.0 Packaging Operations:
6.1 Feed bulk tablets through hopper feeder into preformed pockets.
6.2 Pass through vision system to reject missing or broken tablets.
6.3 Heat-seal foil to blister strip at 160°C sealing temperature under 4 bar pneumatic pressure.
6.4 Cut blister cards into 10-cavity strips at throughput speed of 120 blisters per minute.
6.5 Pack finished blister strips with patient leaflet into cardboard cartons.
7.0 Reconciliation: Perform yield count and calculate packaging accountability.
